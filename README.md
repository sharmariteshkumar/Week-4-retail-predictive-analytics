---

## 📌 Executive Summary

This project develops a predictive pricing model using historical retail data. By leveraging a **Random Forest Regressor**, the model forecasts pricing trends with an **$R^2$ Score of 94.1%**. The predictions and key insights are visually communicated through an interactive **Power BI Dashboard**.

### 🔑 Key Performance Indicators (KPIs)
* **Total Products Analyzed:** 50
* **Average Market Price (Actual):** ₹4,737.00
* **Average Predicted Price:** ₹4,759.49
* **Average Customer Preference Score:** 69.64 / 100
* **Model Accuracy ($R^2$):** **94.1%**
